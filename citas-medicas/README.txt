CITAS MÉDICAS — Sur Salud (Spring Boot + JPA/Hibernate + H2)
================================================================




Inicio rápido
--------------
1. Abre esta carpeta en IntelliJ como proyecto Maven.
2. Corre CitasMedicasApplication.java.
3. Swagger UI: http://localhost:8080/swagger-ui.html
4. Consola H2: http://localhost:8080/h2-console (JDBC URL: jdbc:h2:mem:citasmedicasdb, user: sa)
